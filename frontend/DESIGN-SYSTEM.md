# DesignSystemManifest — 卷影 FolioFrame

> 基于「纸黄墨绿」方向。书籍质感暖色，主色墨绿、点缀赭石，营造旧精装书封面的沉静书卷气。
> 本文档与 0.3.0 代码（index.html 内联 CSS 变量）保持一致，记录当前主题和暗色高对比预览方案。

## 1. 设计方向与禁止项

刻意避开 AI 默认审美：

- 不出现紫色、蓝紫渐变
- 不用赤陶橙 + 奶油底的默认组合
- 不用近黑底配酸性绿（暗色主题用墨绿 + 暖墨黑替代）
- 不用零圆角（避免报纸风），不用大圆角（避免甜腻）

暗色主题面向 OLED 优化：内容区墨绿近黑、侧栏暖墨黑，暗底不用阴影，靠边框分层。

## 2. 主题变量与预览方案

正式设置页当前提供浅色（light）和暗色（dark），并可跟随系统 `prefers-color-scheme`。代码另外保留 `dark-contrast`（暗色·高对比）变量和单文件预览入口，暂未加入正式设置选项。
主题通过 `<html>` 上的 `data-theme` 切换。偏好存于 localStorage：`folioframe_theme`（light / dark）+ `folioframe_theme_auto`（跟随系统）。

### 2.3 暗色·高对比预览（dark-contrast）

这是保留的设计预览方案，暂未出现在正式设置选项中。它比 dark 更冷、更压暗一档，适合低亮度环境：

## 3. 字体

| 角色 | 字体栈 | 应用位置 | 加载方式 |
|---|---|---|---|
| UI 无衬线 | `Sarasa Gothic SC`（更纱黑体），兜底 `Noto Sans SC` / `Microsoft YaHei UI` / `Segoe UI` | 标题、按钮、导航、表单控件、卡片标题 | 本地完整 WOFF2（regular 19.5MB / bold 20.1MB，保留全字符集避免标题回退；TTF 源文件存于项目根 `fonts-source/`，不参与打包） |
| 正文衬线 | `Noto Serif SC` + `Source Serif 4`，兜底 `Songti SC` / `SimSun` | 正文、短评、简介、textarea | Google Fonts CDN |
| 数字等宽 | `IBM Plex Mono` | 进度数字、时间戳、徽章、计数 | Google Fonts CDN |

说明：

- 更纱黑体保留完整字库（含日文汉字），标题确定中文但允许未来混合语种；0.4.0 起分发格式由 TTF 改为 WOFF2，字符覆盖不变，加载与解析更快。
- `assets/fonts/sarasa-gothic-sc-ui-subset.woff2`（145KB）是早期子集化试验品，当前 CSS 未引用，属遗留资产。
- 无衬线负责结构（标题/控件），衬线负责内容（短评/简介），等宽负责数字，三层分工是这套设计的核心可读性策略。

## 4. 字号与行高

- 常用字号阶梯：11 / 12 / 13 / 14 / 15 / 16 / 17 / 20 / 22 / 28
- 大统计数字：34（年度总结）
- 基准字号 16px，正文行高 1.6，标题行高 1.25
- 顶栏标题 20，页面主标题（view-head h1）28，详情标题 22，卡片标题 15，辅助文字 11–13（等宽）

## 5. 间距、圆角、阴影

- 间距基准 4px，标尺：4 / 8 / 12 / 16 / 24 / 32 / 48
- 圆角：卡片 6px，按钮 4px，图片 4px，徽章 999px（胶囊），底部抽屉 16px（仅顶部两角）
- 阴影：浅色用极轻纸张感阴影（见 2.1）；暗色两套均为 `none`，靠 `--rule` 边框分层
- 悬浮：卡片 hover 上浮 2px + hover 阴影（仅桌面）

## 6. 四类媒体字段模板

所有类型共享：标题（可内联编辑）、封面（按季存储，可上传/替换/移除）、状态、评分（1–5 星，按季）、短评（按季）、简介（按季，来自元数据）、收藏、来源标签（Bangumi / TMDB / 微信读书 / 手动）、添加时间、更新时间、看完时间。

**动漫 / 剧集**
- 年份、Studio（动漫）/ 创作者（剧集）
- 季体系：每季独立的进度（第 X 集 / 共 Y 集）、状态、评分、短评、简介、封面
- 剧集进度显示 `第 N 季 E05`，动漫显示 `第 N 集`

**电影**
- 年份、导演
- 看过即完成，无中间态

**书籍**
- 年份、作者
- 进度单位为**章**（`第 X 章 / 共 Y 章`）；页面数对电子书无意义，不设页

## 8. 动效

- 基准过渡 0.2s ease-out；抽屉 0.25s
- 列表项重排：FLIP 位移动画 260ms `cubic-bezier(.2,.8,.2,1)`（替代闪烁动画，对眼睛友好）
- 卡片 hover：上浮 2px（桌面）；active：scale(.99)
- 尊重 `prefers-reduced-motion`：全部降为瞬切

## 9. 响应式断点

- 移动优先，内容区 `--maxw: 480px` 居中
- 600–759px：左右 padding 放宽至 24px
- ≥760px：`--maxw: 960px`，卡片列表双栏 grid
- 主力机三星 Fold 实测视口（Brave 逻辑尺寸）：外屏 475×661、内屏横向 932×616（触发双栏）、内屏竖向 704×845（单栏紧凑）

## 10. 图标

- UI 图标：单色 SVG（home/anime/book/settings/search）+ Icons8 PNG（movie/stats/tv，关于页声明来源）；暗色下通过 CSS filter 反色
- 应用图标 `icon.svg`：墨绿圆角方底 + 米白竖书页 + 赭石描边 + 书脊线；Android launcher 三套资源（adaptive 前景 ×2 + mipmap 位图）以它为准 4x 超采样重绘，脚本 `device-audit/make_icons.py`
