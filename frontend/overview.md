# 卷影 · FolioFrame — 交付总览

## 做了什么
一个本地优先的书影音与故事记录 PWA，覆盖动漫/电影/剧集/书籍四类。数据全存 IndexedDB，可一键导出 JSON。元数据自动从 Bangumi / TMDB / 微信读书抓取，搜不到可手动建条目。

## 产出文件
| 文件 | 作用 |
|---|---|
| `index.html` | 应用主体（单文件，内联 CSS + JS） |
| `manifest.webmanifest` | PWA 安装清单 |
| `sw.js` | service worker，离线缓存 |
| `icon.svg` | 应用图标（纸黄墨绿，"卷"字） |
| `DESIGN-SYSTEM.md` | 设计系统规范（配色/字体/间距/四类字段模板/组件清单） |

## 功能清单（MVP）
- **首页**：在看卡片流，每卡可一键 +1 进度，看完自动转"看过"
- **添加流程**：选类型 → 搜索来源 → 选中预填 → 入库；搜不到走手动表单
- **记录详情**：编辑状态/进度/季/评分(1-10星)/短评，删除
- **全部记录**：按状态 + 类型双维筛选
- **统计**：各状态计数、平均分、类型分布条形
- **设置**：JSON 导出/导入、清空、TMDB key 配置、示例数据
- **PWA**：可"添加到主屏幕"全屏运行，离线可用
- **四类字段模板**：动漫(集)/电影(看过即完)/剧集(季×集)/书籍(页或章)

## 设计系统（纸黄墨绿）
- 底色纸黄 `#F5EFE0`，主色墨绿 `#2D4A3E`，强调赭石 `#B8763A`
- 字体 Noto Serif SC + Source Serif 4（衬线书卷气）+ IBM Plex Mono（数字）
- 刻意避开 AI 默认审美：不用赤陶橙+奶油底、不用紫色蓝紫、不用近黑底酸性绿、不用零圆角报纸风

## 如何使用
1. 本地预览：已起 http 服务在 `http://localhost:8848`
2. 安装到安卓：Chrome 打开 → 菜单 → 添加到主屏幕
3. 用 TMDB 搜电影/剧集前，先在「设置」填 TMDB API key（themoviedb.org 免费申请）
4. 首次空状态可点「载入示例数据」快速体验
